# FIT 디자인 규격

화면을 만들 때 숫자를 새로 고르지 않기 위한 문서입니다. 코드에서는
`src/constants/theme.ts` 의 이름으로만 씁니다.

> 이 문서는 전에 **코드와 어긋나 있었습니다.** 토스 디자인 시스템의 값을
> 적어 두었는데 코드는 그 사이 다른 값으로 옮겨 가 있었고, 문서를 읽고 만든
> 화면이 틀린 색으로 나왔습니다. 아래는 **코드에 실제로 들어 있는 값**입니다.
> 토큰을 고치면 여기도 같이 고쳐 주세요.

> 왜 이렇게 바꿨는지는 [`docs/redesign/plan.md`](../../docs/redesign/plan.md),
> 근거는 [`docs/redesign/research.md`](../../docs/redesign/research.md).

---

## 원칙 다섯

1. **글꼴은 한 가족, 굵기는 네 단계.** 위계는 크기·굵기·색이 함께 만듭니다.
2. **색은 아낍니다.** 화면의 90%는 흰색과 회색입니다. 브랜드색은 *주 동작,
   선택된 것, 링크, 켜진 탭* 에만. 의미색은 정해진 자리에만.
3. **구역은 띠로, 물건은 카드로.** 흰 바탕에 8px 회색 띠로 구역을 나눕니다.
   여행·장소·글처럼 *눌러서 들어가는 물건* 만 카드입니다.
4. **가까운 것은 붙이고 다른 것은 띄웁니다.** 구역 32 > 제목 아래 12 >
   항목 사이 16 > 항목 안 4~8. 모든 것이 왼쪽 20 선에 맞습니다.
5. **주 버튼은 화면에 하나, 자리는 아래.**

> **옛 원칙(흑백·직각·손글씨)은 버렸습니다.** 하나하나는 말이 됐는데 다
> 합치니 스타일을 안 입힌 화면이 됐습니다 — 처음 연 사람에게 「만들다 만
> 것」으로 읽혔습니다.

## 1. 색

### 회색 — 화면의 대부분

글자색은 **네 단만** 씁니다. 그보다 잘게 나누면 어느 것이 더 중요한지가
색으로 안 읽히고, 화면마다 다른 회색이 섞입니다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `surface` / `background` | `#FFFFFF` | 바탕, 카드, 시트 |
| `surfaceRaised` | `#F9FAFB` | 눌린 줄 |
| `band` / `fill` | `#F2F4F6` | **구역 띠**, 회색 면(검색칸·정보 상자) |
| `fillPressed` | `#EAECEF` | 눌린 면, 꺼진 세그먼트 |
| `border` / `divider` | `#E5E8EB` | 구분선, 1px 테두리 |
| `borderStrong` | `#D1D6DB` | 진한 테두리, 시트 손잡이 |
| `textDisabled` | `#B0B8C1` | 못 누름, 자리 표시 글자 |
| `textMuted` | `#8B95A1` | 메타·캡션 (**3차 글자**) |
| `textSecondary` | `#6B7684` | 설명 (**2차 글자**) |
| `text` | `#191F28` | 제목·본문 (**1차 글자**) |

순검정은 안 씁니다.

### 브랜드 — 바이올렛

시안 「FIT 로고 · 앱 아이콘」의 색입니다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `accentSoft` | `#F3F1FF` | 옅은 면 — 켜진 타일, 안 읽은 알림 |
| `accentSoftPressed` | `#E6E2FF` | 그 눌림 |
| `accentDisabled` | `#CEC6FF` | 못 누르는 주 버튼 |
| **`accent`** | **`#6D5BF6`** | **주 버튼, 켜진 스위치·체크, 링크, 켜진 탭, 지도 핀** |
| `accentPressed` | `#5A45E6` | 주 버튼 눌림 |
| `accentText` | `#4935C4` | 옅은 면 위의 글자 |
| `onAccent` | `#FFFFFF` | 바이올렛을 채운 면 위의 글자 |

흰 글씨와 5.3:1 이라 **가득 칠해도 읽힙니다.** 옛 코랄은 그게 안 돼서 주
단추를 옅은 물에 색 글씨로 뒤집어야 했고, 그 결과 흰 판 위에서 꺼진 단추처럼
보였습니다.

### 노랑 — 「지금 · 곧」

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `hot` / `star` | `#FFD43B` | D-day·여행 중 배지, 별점, 지금 시각 선 |
| `hotSoft` | `#FFF6D1` | 방금 넣은 장소에 1.5초 깔리는 바탕 |
| `onHot` | `#191F28` | 노란 면 위의 글자. **늘 Ink** |

심볼의 기울어진 알약에서 온 색입니다. 그 알약은 「일정 칸에 들어가는 한
자리」를 뜻합니다. **글자색으로는 안 씁니다** — 흰 바탕에서 1.6:1 입니다.

### 의미색 — 색마다 하는 일이 하나

| 이름 | 값 | 옅은 면 | 쓰는 곳 |
|---|---|---|---|
| `danger` | `#E5383B` | `#FFF0F0` | 지우기, 나가기, 오류 |
| `success` | `#0E9F6E` | `#E8F7F1` | **받을 돈**, 완료, 정해짐 |
| `warning` | `#F2690D` | `#FFF3EA` | **줄 돈**, 마감 임박 |
| `like` | `#FF4D5E` | `#FFF0F2` | 하트 |

전에는 위험도 성공도 전부 먹색이었습니다("위험한 것은 모양으로 가린다").
그런데 가계부의 받을 돈과 줄 돈을 모양으로 가를 방법이 없었습니다.

### 날짜 색 여덟 — `DayColors`

`#3B82F6 · #F97316 · #10B981 · #EC4899 · #06B6D4 · #84CC16 · #B45309 · #64748B`

지도 핀·동선·날짜 칩에만 씁니다. 뜻이 있는 색이 아니라 이름표입니다.
**바이올렛과 노랑은 뺐습니다** — 브랜드색과 「지금」이 이름표에 섞이면 그 둘이
무엇을 뜻하는지 흐려집니다.

## 2. 글자

웹은 **Pretendard**(`public/fonts/PretendardVariable.woff2`, 가변 45~920),
앱은 기기 고딕입니다. iOS 의 Apple SD Gothic Neo 는 Pretendard 가 본뜬
글꼴이고 안드로이드의 Noto Sans KR 도 같은 계열이라, 굵기 네 단계가 다
있습니다.

| 토큰 | 크기/줄높이 | 자간 | 쓰는 곳 |
|---|---|---|---|
| `display` | 28/36 | -0.4 | 여행 히어로 제목, 홈 첫 줄 |
| `title1` | 24/32 | -0.3 | 탭 화면 큰 제목, 합계 금액 |
| `title2` | 20/28 | -0.2 | 구역 제목, 시트 제목 |
| `title3` | 18/26 | 0 | 다이얼로그·상단바 제목, 큰 카드 제목 |
| `headline` | 16/22 | 0 | 목록 제목, 카드 제목, 큰 버튼 글자 |
| `body` | 16/24 | 0 | 본문, 입력 글자 |
| `body2` | 15/22 | 0 | 설명, 카드 본문 |
| `caption` | 13/18 | 0 | 메타(날짜·거리·개수), 힌트, 오류 |
| `micro` | 11/14 | 0 | 하단 탭 글자, 배지, 지도 핀 글자 |
| `label` | 12/16 | 1.2 | 구역 이름표 — 넓게 벌린 작은 글자 |

- **화면 하나에서 쓰는 것은 셋 이하.** 넷을 넘기면 어느 것이 중요한지가 안
  보입니다.
- 굵기: `regular 400` · `medium 500` · `semibold 600` · `bold 700`.
- 자간 음수는 큰 글자에만. 작은 글자를 조이면 한글 받침이 서로 닿습니다.
- 숫자가 자릿수로 줄 맞춰야 하는 자리(금액·시간·개수)에는 `Tabular` 를 함께.

`body` 는 16 아래로 못 내립니다 — iOS 사파리가 입력할 때 화면을 확대합니다.

## 3. 간격 · 모서리 · 그림자

### 간격 — 4의 배수

`s1 4` · `s2 8` · `s3 12` · `s4 16` · `s5 20` · `s6 24` · `s8 32` ·
`s10 40` · `s12 48` · `s16 64`

| 자리 | 값 |
|---|---|
| 화면 좌우(`Gutter`) | 20 |
| 구역 위 | 32 |
| 구역 제목 → 내용 | 12 |
| 목록 항목 사이, 카드 안쪽 | 16 |
| 칩 사이, 아이콘과 글자 | 8 |
| 구역 띠(`BandHeight`) | 8 |

옛 이름(`xs sm md lg xl xxl xxxl huge`)은 같은 격자 위의 별칭입니다. 새로
쓰는 자리는 `s1~s16` 을 씁니다.

### 모서리

`r1 4`(배지·태그) · `r2 8`(썸네일·작은 버튼) · **`r3 12`**(버튼·입력칸·목록
카드·세그먼트) · `r4 16`(사진 카드·큰 카드·스낵바) · **`r5 20`**(바텀시트 위
모서리·다이얼로그) · `full 999`(칩·스위치·아바타)

### 그림자 — `Elevation`

평평한 것이 기본입니다. **진짜로 떠 있는 것**에만 줍니다.

| 토큰 | 쓰는 곳 |
|---|---|
| `none` | 띠·목록·면 카드 |
| `card` | 흰 바탕 위 카드, 세그먼트의 흰 손잡이 |
| `float` | 지도 위 단추·칩, 스낵바, 바닥 고정 바 |
| `sheet` | 드래그 시트(위쪽으로 드리움) |
| `dialog` | 다이얼로그, 팝오버 |
| `pin` | 지도 위 핀 |
| `layerOnly` | 안드로이드에서 레이어만 올리고 그림자는 안 그림 |

`shadowOpacity` 를 빼먹으면 iOS·웹에서 **아무것도 안 보입니다**(기본값 0).
안드로이드는 `elevation` 을 따로 봅니다 — 둘을 같이 적어야 합니다.

## 5. 아이콘

**Ionicons** 한 세트입니다(`@expo/vector-icons` 에 이미 있음). 화면은 옛
이름(`map-pin`, `chevron-right` …)을 그대로 부르고, `ui/index.tsx` 의 표가
Ionicons 이름으로 번역합니다. `solid` 를 주면 채운 그림이 나옵니다 — 아래
갈래 띠의 켜진 칸이 이것을 씁니다.

> 페더(Feather)에는 채운 그림이 없어서 켜짐·꺼짐을 색 하나로만 갈라야 했고,
> 그러면 띠를 흘긋 봐서는 어느 칸에 있는지 모릅니다. 세트를 섞으면 획 굵기가
> 달라 엉성해 보이므로 하나로 통일합니다.

장소 갈래 이모지(`place-icons.ts`, `user-marks.ts`)는 그대로 둡니다.

## 6. 움직임 — `Motion`

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `tap` | 100ms | 눌림 |
| `base` | 200ms | 색·투명도, 스위치 |
| `sheet` | 280ms | 시트·다이얼로그 |
| `spring` | damping 24 / stiffness 260 | 세그먼트 손잡이, 시트 스냅 |

보입니다.

## 7. 넓은 화면 — `ui/layout.ts`

| 단계 | 너비 | 배치 |
|---|---|---|
| `phone` | < 768 | 위 그대로 |
| `tablet` | 768–1023 | 본문 최대 680 가운데, 카드 2열 |
| `desktop` | ≥ 1024 | 본문 최대 960, 카드 3열, 왼쪽 사이드바 240 |

너비를 재는 자리는 `useBreakpoint()` 하나입니다. 부품마다 숫자를 따로 적어
두면 어떤 것은 768에서 어떤 것은 800에서 바뀌어, 그 사이 폭에서 화면이 반쯤
바뀐 모양이 됩니다.

## 8. 화면 점검표

새 화면을 만들거나 고친 뒤에 봅니다.

- [ ] 글자 단계가 화면 하나에 **셋 이하**인가
- [ ] 브랜드색으로 **채운 것이 하나**인가
- [ ] 모든 글자가 왼쪽 **20 선**에 맞는가
- [ ] 구역 사이 **32**, 제목 아래 **12** 인가
- [ ] 터치 영역이 **44 이상**인가
- [ ] **빈 상태 · 불러오는 중 · 오류** 화면이 다 있는가
- [ ] 시스템 글꼴 **130%** 에서 안 깨지는가
- [ ] `npm run typecheck` 가 깨끗한가

대비는 `text`/흰색, `textSecondary`/흰색이 AA(4.5:1) 이상입니다.
`textMuted` 는 **13px 이상에서만** 씁니다.
