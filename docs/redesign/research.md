# 디자인 개편 — 상용 앱 조사

> 2026-10-01. 개편 계획(`plan.md`)이 기대는 근거입니다.
> 한 앱을 베끼지 않습니다. 여러 앱이 **같이 하는 것**을 뽑고, 갈리는 곳에서는
> FIT 에 맞는 쪽을 고릅니다.

## 0. 왜 바꾸나 — 지금 화면의 문제

현재 화면은 "아마추어가 그린 것"처럼 보입니다. 사람들이 일정과 돈을 맡길 앱으로
믿기 어렵습니다. 원인은 몇 가지로 좁혀집니다.

| 문제 | 지금 | 상용 앱 |
|---|---|---|
| 글꼴 | 화면 전체가 **이서윤체(손글씨)** | 모두 고딕 한 가족(시스템 폰트 또는 Pretendard). 손글씨 UI는 하나도 없음 |
| 굵기 | 굵기 이름은 다섯 개인데 값은 모두 `'400'` → 굵기가 사실상 하나 | 400 / 500(600) / 700 세 단계로 위계를 만듦 |
| 크기 | 본문 20, 제목 34, 캡션 15 | 본문 14~16, 화면 제목 20~24, 캡션 11~13 |
| 위계 | 소제목·목록 제목·본문이 모두 20/400 → 서로 구분이 안 됨 | 크기 차이 2~4px에 굵기와 색까지 함께 바꿈 |
| 강조색 | 주 버튼도 옅은 분홍 바탕에 코랄 글씨. 꽉 찬 색이 거의 없음 | **주 동작 하나만** 브랜드색으로 꽉 채움 |
| 의미색 | 위험·성공·강조가 모두 검정 | 위험은 빨강, 받을 돈은 초록 같은 의미색이 정해져 있음 |
| 모서리 | 0, 6, 12, 17, 24가 섞임. 스위치와 입력칸은 네모 | 4~5단계 토큰. 스위치는 둥근 알약 모양 |
| 입력칸 | Field는 밑줄, DateField는 회색 상자 | 한 가지 모양 |
| 하단 탭 | 떠 있는 반투명 알약 + 그림자. 어떤 화면에는 있고 어떤 화면에는 없음 | 바닥에 붙은 흰 띠 + 위 1px 선. 탭 화면에는 항상 있음 |
| 로고·아이콘 | 손글씨로 구운 그림 | 굵은 고딕 워드마크 또는 심볼 |

색 단계(회색 아홉 개)와 화면 뼈대(Screen·Card·BottomSheet 같은 공용 부품)는 쓸 만합니다.
공용 부품이 `src/ui` 한곳에 모여 있어서 **토큰과 부품을 바꾸면 화면 대부분이 한 번에
바뀝니다.**

## 1. 레퍼런스 화면 읽기

### 1-1. 트리플 (브런치 「트리플 분석」에 실린 앱 캡처 6장)

글 본문은 서비스·PM 분석입니다. 디자인 근거는 캡처에서 읽었습니다.

**① 여행 홈 (삿포로 여행, D-2)**
- 위쪽 약 35%를 브랜드색(청록)이 꽉 채운 **히어로**가 차지합니다. 제목은 두 줄
  "삿포로 여행, / D-2"이고 약 28pt 굵게 흰 글씨입니다. 날짜는 밑줄 링크이고
  "편집" 링크가 붙어 있습니다. "+ 도시추가"는 반투명 알약 버튼입니다.
- 바로 아래에 **글자만 있는 가로 탭**(가이드·항공·숙소·관광·맛집·투어·라운지)이
  옆으로 넘어갑니다. 화면 밖으로 잘리게 두어 더 있다는 것을 알립니다.
- 구역마다 흰 블록이고, 블록 사이를 **8~10px 회색 띠**가 가릅니다.
  카드 테두리도 그림자도 없습니다. 분리감은 회색 띠 하나가 만듭니다.
- 구역 안: 제목 약 20 굵게, 설명 15 회색 두 줄. 맨 아래 오른쪽 정렬 파란 밑줄 링크
  ("입국 정보 및 마스크 현황 확인").
- 광고 카드: 제목 + 설명은 왼쪽, 3D 일러스트는 오른쪽. 오른쪽 위에 작은 "AD" 표시.
- 하단 탭 4칸(여행 홈·일정·여행 도구·저장): 선 아이콘 약 24, 라벨 약 11, 켜진 칸만
  검정이고 나머지는 회색. 흰 띠에 위쪽 가는 선.

**② 항공 검색 결과**
- 머리: ← + **두 줄 제목**("서울 - 삿포로 ⌄" 17 굵게 / "성인1, 일반석 외 1" 13 회색).
  부모 문맥을 경로(breadcrumb)가 아니라 **부제**로 보여 줍니다.
- 필터 줄: 선택된 것은 파랑으로 꽉 채운 직사각 칩(r 약 4), 나머지는 1px 테두리 칩.
- 프로모션 카드: 연회색 면, r 약 8, 설명 두 줄 + 오른쪽 아이콘.
- 가로 캐러셀: 다음 카드가 화면 끝에서 잘려 보입니다(peek).
- 결과 머리 "검색결과"(18 굵게) + 오른쪽 메타 "260개, 왕복…"(13 회색) → **한 줄에
  제목과 메타가 양끝 정렬**.
- 결과 행: 시간 18 굵게 / 공항·항공사 14 회색. 오른쪽에 소요 시간 / 수하물이
  오른쪽 정렬. 행 사이는 선 없이 여백만.
- 가격: "최저"(작은 빨강) + **831,800원(22 굵게)**. 잔여 배지 "2개 남음"(청록으로 채움, 작게).
- 1px 테두리 전체 폭 버튼 "KB국민카드 외 4개 요금 더보기 ›" (높이 약 48).

**③ 숙소 상세**
- 섹션 제목 "기본정보" 약 22 굵게, 위아래 여백이 넉넉함(약 40/24).
- 지도 r 약 8. 그 아래 **연회색 정보 상자**: 라벨(굵게)과 값을 두 줄로 정렬.
- **버튼 둘을 나란히**: 보조(흰 바탕 + 1px 테두리) "현지에서 길묻기"와 주(파랑으로 채움)
  "길찾기". 높이 약 52, r 약 4, 같은 폭.
- 줄 목록 "숙소 찾아가는 방법 ›" + 설명 한 줄.
- **하단 고정 바**: 왼쪽에 브랜드 라벨 "TRIPLE"(작게, 청록) / 가격 22 굵게 / 날짜 밑줄,
  오른쪽에 주 버튼 "객실 보기". 정보와 행동이 한 띠에 같이 있습니다.

**④ 오프라인 가이드 목록**
- 행: 원형 썸네일 약 64 + 제목 17 굵게 / 지역 14 회색 / 용량 13 연회색 + 오른쪽 원형
  아이콘 버튼(1px 테두리, 다운로드).
- 그 아래 아코디언("일본 ⌄", "동남아시아 ⌄"): 선 없이 줄 높이 약 64로 넉넉히.

**⑤ 여행자 클럽**
- 일러스트 히어로 → 섹션 제목 17 굵게 → 본문 15 회색, 줄 높이 약 1.6.
- 혜택 목록은 **흰 카드 하나 안의 행들**. 아주 옅은 그림자, 행 사이는 가는 선.
  행마다 색 아이콘 약 28을 둠. 색은 아이콘에만 씁니다.
- 끝에 전체 폭 테두리 버튼.

**⑥ 리뷰 목록**
- 아바타 40 + 이름 16 굵게 / "LEVEL1 / 4개의 리뷰" 13 회색 → 별점(노랑) → 본문 16 →
  전체 폭 사진(r 약 4) → 메타 줄(좋아요·댓글 아이콘+숫자 13, 날짜, ⋯).
- 리뷰 사이는 1px 선 + 위아래 약 24 여백.

### 1-2. Gotour 여행 앱 UI 키트 (Pinterest)

- **한 가지 강조색(주황)** 을 주 버튼, 검색 버튼, 가격 배지, 선택된 타일, 켜진 탭
  아이콘에만 씁니다. 나머지는 흰색과 연회색입니다.
- 카드: **연회색 면(약 #F6F6F6) + r 12~16, 테두리·그림자 없음.** 흰 화면 위에서 면
  색만으로 덩어리가 보입니다.
- 목록 카드: 정사각 썸네일 약 60(r 10) + 제목 15 굵게 + 📍 위치 12 회색 + 태그
  칩(회색 면, 11) + 오른쪽 가격 배지(주황, r 6).
- 이미지 카드: 사진을 가득 채우고 **아래쪽 어두운 그라데이션 위에 흰 글씨**를 얹습니다.
  가로 캐러셀에서 다음 카드가 잘려 보입니다.
- 검색: 1px 테두리 입력칸 + 오른쪽에 **정사각 주황 아이콘 버튼**.
- 선택 그리드(Discover): 2열 타일, 꺼짐은 회색 면이고 켜짐은 주황으로 채움.
  선택한 필터는 위쪽에 "Europe ×" 알약으로 모입니다.
- 설정: **회색 둥근 패널 안에 그룹** (그룹 제목 → 아이콘 16 + 라벨 + ›).
  로그아웃만 주황으로 채운 전체 폭 버튼입니다.
- 일정 진행: "15 Feb ──✈── 22 Feb" 진행선이 있습니다. 여행 중 화면에 쓸 만합니다.
- 주의: 제목에 가는 굵기(Light)를 쓰는데, 트리플·국내 앱과 비교하면 신뢰감은 떨어집니다.
  **여백, 면 카드, 강조색 한 가지라는 원칙만 가져옵니다.**

### 1-3. 배치 · 분리감 · 공간감 — 두 레퍼런스에서 뽑은 규칙

| 주제 | 관찰 | FIT 규칙 |
|---|---|---|
| 구역 분리 | 트리플은 흰 블록 사이 8~10px 회색 띠. Gotour는 흰 바탕 위 회색 면 카드 | 정보 화면은 **흰 바탕 + 8px 띠**. 물건(여행·장소·글)은 **카드** |
| 구역 안 리듬 | 섹션 위 여백 32~40 > 제목→내용 12~16 > 항목 사이 12~20 | 바깥 32 / 제목 아래 12 / 항목 사이 16 / 항목 안 4~8. **가까운 것은 붙이고 다른 것은 띄움** |
| 정렬 | 모든 글자가 왼쪽 20px 선에 맞음. 숫자와 메타만 오른쪽 정렬 | 왼쪽 정렬 기본. 금액·시간·개수는 오른쪽 정렬 |
| 제목 줄 | "제목 ……… 메타/더보기 ›" 양끝 정렬 | SectionHeader 하나로 통일 |
| 버튼 배치 | 화면의 주 동작은 **하단 고정 바**. 두 개면 보조(왼쪽, 좁게) + 주(오른쪽, 넓게) | 하단 고정 CTA 바. 주 버튼은 화면에 하나 |
| 링크 동작 | "더보기"는 버튼이 아니라 오른쪽 정렬 텍스트 링크나 행 끝 › | 가벼운 이동은 텍스트·행으로 |
| 가로 넘김 | 다음 카드가 잘려 보이게 둬서 넘길 수 있음을 알림 | 캐러셀 카드 폭 = 화면 − 20 − 48 |
| 색의 양 | 화면의 90% 이상이 흰색·회색. 색은 CTA, 선택, 가격, 아이콘에만 | 브랜드색은 주 버튼, 선택, 링크, 켜진 탭에만 |
| 밀도 | 한 화면에 섹션 3~4개가 보임(트리플 홈) | 본문 16 / 여백 4pt 격자로 지금보다 밀도를 약 1.4배 높임 |

## 3. 합의된 것 / 갈리는 것

**거의 모든 앱이 같이 하는 것**
- 고딕 한 가족. 굵기 3단계. 손글씨·장식 서체는 UI에 쓰지 않음.
- 본문 14~16, 목록 제목 15~16, 화면 제목 20~24, 캡션 11~13.
- 줄 높이: 한 줄 1.2~1.35, 여러 줄 1.45~1.55. 자간 0.
- 강조색은 **하나**, 주 동작에만. 의미색(위험·성공·하트·별점)은 따로 정함.
- 글자색 회색은 3~4단계. 순검정(#000)은 쓰지 않음.
- 주 버튼 48~56, 보조 36~44, r8~12.
- 입력칸 48~52, r8~12, 1px 테두리, 포커스 때 굵게·색으로.
- 칩 32~36, 완전 둥근 모서리.
- 목록 한 줄 48~56, 두 줄 64~72.
- 상단바 56, 하단 탭 49~56(+안전영역), 아이콘 24, 라벨 10~12.
- 시트: 위 r20~28, 손잡이 32~36×4, 최대 90%, CTA는 아래 고정.
- 다이얼로그 r14~28. 스낵바는 어두운 바탕, 아래쪽.
- 4pt 격자. 좌우 여백 16~20.

**갈리는 것 (FIT 의 선택은 `plan.md` 에)**
- 구역을 나누는 방식: 흰 바탕 + 띠(트리플·당근) / 회색 바탕 + 흰 카드(여기어때).
- 그림자: 거의 안 씀(당근·Trip.com) / 단계별로 씀(여기어때·트리플).
- 주 버튼 색: 검정(당근) / 브랜드색(여기어때·NOL·트리플).
- 브랜드색 계열: 따뜻한 색(당근·여기어때) / 파랑(NOL·트리플·Booking·Expedia).
- 글꼴: 시스템 폰트(당근·11번가) / Pretendard(여기어때·원티드).
