# 여행 중에 쓰는 것 — 어디까지 왔나

> 조사 → 판단까지 끝났습니다.
> **구현 계획(3단계)을 아직 안 썼습니다. 코드는 한 줄도 안 바뀌었습니다.**
>
> 셋 중 **가장 덜 간 폴더**입니다. 버려 둔 것이 아니라 관문 둘이 안 풀려
> 멈춘 것이고, 그 관문이 무엇인지 아래에 적어 두었습니다.

## 줄기에서 어디쯤인가

이 조사는 혼자 선 것이 아닙니다. 앞뒤가 있습니다 — [`docs/README.md`](../README.md).

```
docs/2026-09/  survey.md 의 "아무도 안 하는 것" 이 이 조사를 가리켰습니다
      v
docs/during-trip/  ← 여기
      v
docs/replan/   이 폴더 verdict.md 의 "조사에 없었지만 눈에 띈 자리" 가 그 조사를 낳았습니다
```

**꼬리가 실제로 맞았습니다.** `verdict.md` 끝에 "다음 조사를 이쪽으로 하면
1차가 다시 생길 가능성이 큽니다" 라고 적었는데, `docs/replan/` 이 그대로
1차 넷을 냈고 **전부 서버 0 · 구글 0 · 재빌드 0** 입니다.

## 왜 멈춰 있나

### 이 조사에는 1차가 없습니다

받기로 한 다섯이 **전부** 새 바깥문이거나 재빌드입니다(`verdict.md` 0.1).

| 받는 것 | 무엇이 필요한가 |
|---|---|
| 5 날씨 | 서버 (새 바깥문) |
| 6 환율 어림 | 서버 (새 바깥문) |
| 4 실시간 출발 | 서버 (구글 호출 늘어남) |
| 1 현지 글자 이름 | 서버 + 스키마 |
| 12.2 빨리 넣기 | EAS 재빌드 |

여행 중 기능에 싼 것이 없는 데는 이유가 있습니다. 계획은 이미 우리 DB 에
있는 것을 다시 보여 주는 일이 많고, 여행 중은 **지금 바깥에서 벌어지는 일**을
알아야 합니다.

### 관문 둘이 사람 손에 있습니다

| 관문 | 무엇이 걸려 있나 |
|---|---|
| **이 앱이 상업인가** | 5번(날씨)의 값이 여기서 갈립니다 — Open-Meteo 무료는 비상업 전용, 월 $0 또는 $29. 모호하면 상업으로 봅니다 |
| **Routes API 요금 등급표** | 4번(실시간 출발)의 값을 못 셉니다. 세 조사에 걸쳐 세 번 못 봤습니다 |

**관문이 안 풀린 계획은 미리 쓰지 않습니다.** 관문 너머가 달라지면 두 번
쓰게 됩니다. `docs/replan/README.md` 가 같은 이유로 3차 둘을 안 썼습니다.

### 그래서 다음에 할 것

**계획을 쓰기 전에 상업 여부부터 정해야 합니다.** 정해지면 5번(1순위)부터
계획 문서를 씁니다. 4번은 요금 등급표를 봐야 하고, 12.2 는 EAS 재빌드라
`docs/2026-09` 의 대기 둘과 같이 묶입니다.

## 이 조사가 찾아 둔 것

### 문턱이 없는 바깥문

`verdict.md` 0.2 가 짚은 것입니다. 구글 문턱은 이름 그대로 **구글만** 셉니다.
날씨·항공·환율은 그 넷 어디에도 없어서 **아무도 안 셉니다.**

그래서 5·6번의 조건에 "문턱을 함께 만든다" 가 들어 있습니다. 붙이고 나서
세는 것을 잊으면, 지금 구글에 서 있는 규율이 새 문에는 안 섭니다.

> 이 절은 `GoogleQuotaFilter.callsOf` 를 인용해 썼는데 그 메서드는 이제
> 없습니다(`docs/done/plan-quota.md`). **논지는 그대로이고 오히려 더
> 분명해졌습니다** — 세는 자리가 넷으로 못박혀서, 그 밖은 더 확실히
> 안 세어집니다. 본문에 정정 상자를 얹어 두었습니다.

### 두 후보가 이미 있었습니다

8번(Ask Maps)과 13번(일행과 흩어졌을 때)입니다. `RecommendService` 와
`LiveService` 가 이미 합니다.
