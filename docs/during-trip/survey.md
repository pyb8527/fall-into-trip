> 2026-09-11 에 **여행 중**(길 위에서 쓰는 것)만 따로 본 기록입니다.
> 판단은 `verdict.md` 에서 합니다. 여기서는 좋다·나쁘다를 쓰지 않습니다.
> 아직 코드는 한 줄도 바뀌지 않았습니다.

## 왜 이 축인가

지난 조사가 그것을 가리켰습니다. `docs/2026-09/survey.md` 의 "아무도 안 하는
것" 절에 이렇게 적어 두었습니다.

> **여행 중에 쓰는 것.** 대부분이 여행 **전**(계획)과 **후**(기록)에 무게가
> 있습니다. Polarsteps 는 후, Wanderlog 는 전입니다. 여행 중은 Flighty 같은
> 항공편 앱이 Live Activity 로 가져가 있습니다.

지난 조사의 열다섯은 대부분 계획 단계의 것이었습니다. 이번에는 **떠난 다음**
으로 범위를 좁혔습니다. 겹치는 것은 뺐습니다 — 오프라인 일정 열람(지난 1번),
잠금화면 위젯·Live Activity(14번), 위치 자취(12번), 여행 후 요약(13번),
입구 좌표(5번), 가까운 역(7번), 가는 길 위에서 찾기(3번)는 다시 조사하지
않았습니다.

## 1. 메뉴와 간판을 그 자리에서 읽기 (카메라 번역)

**한 줄** — 폰을 메뉴에 대면 그 위에 번역된 글자가 얹힙니다.

**어떻게 동작하나**
Google Translate 의 카메라(Live View) 모드입니다. 언어 묶음을 미리 받아 두면
**데이터 없이도 됩니다.** 133개 언어를 지원하고 오프라인은 70개 이상입니다.
다만 음성 입력을 오프라인으로 쓰려면 **말소리 묶음을 따로** 받아야 합니다 —
글자 묶음과 다른 파일입니다.

Apple Translate 는 아이폰에 기본으로 들어 있고 전부 기기 안에서 처리합니다.

**플랫폼이 새로 열어 준 것 — 그리고 그 한계**
브라우저에 번역이 들어왔습니다. Chrome 의 Translator API 와 Language
Detector API 입니다.

|---|---|
| 어디서 되나 | **Chrome 138 이상, Edge 148 이상** |
| 모바일 | **안 됩니다.** 문서가 그대로 적어 두었습니다 — "The Language Detector and Translator APIs work in Chrome on desktop. These APIs don't work on mobile devices." |
| 언어 | 45개 이상 |
| 모델 | 브라우저에 딸려 있고 **처음 쓸 때 내려받습니다.** `downloadprogress` 로 진행을 볼 수 있습니다 |
| 어디서 도나 | 기기 안. 글자가 밖으로 안 나갑니다 |
| 그 밖에 | 번역이 **순서대로** 처리되므로 많이 넣으면 뒤엣것이 줄을 섭니다 |

## 3. 오프라인 지도

**한 줄** — 지역을 미리 받아 두면 데이터 없이 지도와 길찾기가 됩니다.

**어떻게 동작하나**
Google Maps 의 오프라인 영역입니다. 2026 기준으로 **네모 조각이 아니라 지역
단위**로 받을 수 있고, 신호가 없는 곳에서도 **내려받은 장소 목록으로 주변
검색**이 됩니다.

**한계가 분명합니다.** 오프라인에서 되는 것은 자동차 길안내이고,
**대중교통 길찾기와 실시간 교통 정보는 안 됩니다.**

**사람들이 겪는 것**
"연결이 끊기는 것" 이 여행 중 불편의 첫자리로 나옵니다. 다만 **이 수치는
eSIM 판매 업체의 자료입니다** — 그쪽은 이 문제가 커 보일수록 이득입니다.
그대로 옮기되 출처를 밝힙니다.

## 6. 현지 가격을 원화로

**한 줄** — "1,200엔" 옆에 "약 11,400원" 이 붙습니다.

**어떻게 동작나**
한국에서는 이것만 하는 앱이 한 갈래로 서 있습니다. 트레블크럼, 환율 계산기
같은 것들입니다. 공통점이 하나 있습니다 — **오프라인에서 됩니다.** 마지막에
받아 둔 환율로 셈하고, 비행기 모드에서도 열립니다.

트리플은 환율을 "여행 필수 기능" 묶음에 넣어 앱 안에 두고 있습니다.

**무엇을 요구하나**

| 항목 | |
|---|---|
| 위치 | 불필요 |
| 사진·파일 | 불필요 |
| 푸시 | 불필요 |
| 외부 API | **환율 하나** |
| 서버 저장 | 환율 표 한 줄. 파일이 아닙니다 |
| 구글 호출 | 0 |

**FIT 쪽 사실** — 통화는 다루지만 **환율은 없습니다.**
`Currencies.java:30-44` 가 코드를 다듬고 `:51-59` 가 자릿수를 JDK 에서
읽습니다. 자릿수 표를 손으로 안 들고 있는 이유가 주석에 적혀 있습니다 —
"손으로 적어 두면 언젠가 어긋나고, 그 어긋남은 돈 계산에서 드러납니다."
`COMMON` 에 열 통화가 있습니다(`:24-25`).

**규칙에 정면으로 걸립니다** — "통화를 합치지 않습니다"
(`references/house-rules.md`). 엔과 원을 더하려면 "언제 환율로" 가 남고 그
답은 사람마다 다릅니다. 다만 **더하는 것**과 **나란히 보여 주는 것**이 같은
일인지는 2단계에서 갈라야 합니다.

**확인 못 한 것** — 무료로 쓸 수 있는 환율 출처가 무엇인지 안 찾았습니다.
한국은행·ECB 가 후보일 텐데 확인 안 했습니다.

## 눈에 띈 것

**여럿이 공통으로 가진 것**

- **오프라인이 여기서도 갈림입니다.** 번역 묶음, 지도 영역, 경로 저장,
  환율 표 — 여행 중 기능은 거의 다 "데이터 없을 때 되는가" 로 값이 갈립니다.
  그리고 대개 **미리 받아 두는 것**이 답입니다.
- **잠금화면이 전장입니다.** Google Wallet 의 Live Updates, Flighty 의 Live
  Activity, TravelSpend 의 위젯. 여행 중에는 앱을 여는 것조차 일이라는 판단이
  깔려 있습니다.
- **번역은 OS 가 가져갔습니다.** Apple Translate 는 기본 탑재·완전 오프라인,
  Chrome 은 브라우저에 넣었습니다. 여행 앱이 자체 번역을 만드는 사례를 못
  봤습니다.

**아무도 안 하는 것**

- **여행 중에 일정이 흐트러지는 것을 다루는 곳이 없습니다.** 비가 오거나 줄이
  길어서 하나를 건너뛰면, 그 뒤가 전부 밀립니다. 조사한 열셋 중 이것을 다루는
  것이 없었습니다. 계획 앱은 짜는 것까지, 지도 앱은 한 구간까지입니다.
  (FIT 에는 `RouteTidy` 와 "사람이 수락해야 바뀝니다" 규칙이 이미 서 있는
  자리입니다.)
- **여럿이 함께 움직이는 것.** 위치 공유는 여럿이 하지만, "지금 다들 이
  일정에 동의하는가" 를 길 위에서 묻는 곳은 없었습니다. FIT 의
  `CandidateService`(전원 동의)가 계획 단계에만 쓰이고 있습니다.

**값이 드는 것이 뚜렷하게 갈립니다**

여행 중 기능은 계획 기능보다 **바깥문이 더 많이 생깁니다.** 지난 조사에서는
후보 열다섯이 거의 다 구글 하나로 끝났는데, 이번에는 셋이 새 바깥문을
요구합니다.

| 후보 | 새 바깥문 | 값 |
|---|---|---|
| 5 날씨 | 날씨 API | 상업이면 월 $29 부터 (Open-Meteo) |
| 11 항공편 | 항공 데이터 API | 월 $49.99 부터. 게이트는 엔터프라이즈 |
| 9 혼잡도 | 남의 혼잡도 API | 구글이 안 팝니다 |
| 6 환율 | 환율 출처 | 안 찾아봤습니다 |

`GoogleQuotaFilter` 는 이름 그대로 **구글만** 셉니다. 새 바깥문이 생기면
그 문은 아무도 안 셉니다.

**웹과 앱이 갈리는 것이 이번에는 대부분입니다**

지난 조사에서는 재빌드가 필요한 것이 둘이었습니다(앱 오프라인·위젯).
이번에는 열셋 중 **여섯이 네이티브**입니다 — 1(카메라)·2(마이크)·3(지도
타일)·7(AR)·10(지갑)·12(단축어·위젯). Chrome 의 번역 API 마저 데스크톱
전용이라, **폰으로 여행 중에 쓰는 웹**에서는 그것도 안 됩니다.

**조사에서 못 채운 자리**

- **레딧을 또 못 봤습니다.** 크롤러가 막혀 있습니다. 불평 축은 리뷰 매체와
  한국어 커뮤니티 글, 그리고 eSIM 업체 자료로 메웠습니다.
- **이해관계가 있는 출처를 둘 썼습니다.** 연결 문제 수치(eSIM 판매 업체)와
  혼잡도 대안(경쟁 API 판매 업체). 둘 다 본문에 누가 낸 자료인지 적었습니다.
- **Routes API 의 요금 등급표를 안 봤습니다.** 4번의 값을 못 셉니다. 지난
  조사에서 Places 쪽은 확인했는데 Routes 쪽은 이번에도 못 봤습니다.
- **경쟁 앱을 직접 써 보지 않았습니다.** NAVITIME 의 "50개 오프라인 저장"
  같은 것은 스토어 설명을 옮긴 것입니다.
- **숫자는 출처가 있는 것만 적었습니다.** 값(API 요금)과 조사 수치는 출처를
  달았고, 나머지는 안 적었습니다.
