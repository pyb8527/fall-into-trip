# docs — 무엇이 어디에 있나

폴더가 넷입니다. 처음 보면 흩어져 있는 것처럼 보이는데, **셋은 한 줄기**
입니다. 조사 하나가 끝날 때마다 다 못 본 자리를 남기고, 다음 조사가 거기서
시작했습니다.

```
docs/2026-09/        (2026-09-11)  전반 — 경쟁 앱·플랫폼에서 열다섯
      │  survey.md 의 "아무도 안 하는 것" 이 다음을 가리켰습니다
      v
docs/during-trip/    (2026-09-11)  여행 중 — 길 위에서 쓰는 것 열셋
      │  verdict.md 의 "조사에 없었지만 눈에 띈 자리" 가 다음을 가리켰습니다
      v
docs/replan/         (2026-09-14)  일정이 흐트러진 뒤 — 열둘
```

그래서 **뒤 조사는 앞 조사가 본 것을 다시 안 봅니다.** `replan/survey.md` 가
날씨·실시간 출발·항공편·위젯을 "여기서는 다시 조사하지 않았습니다" 라고
적어 둔 것이 그 때문입니다. 한 폴더만 읽으면 빠진 것처럼 보이는 자리가 있고,
그건 옆 폴더에 있습니다.

넷째는 줄기가 아니라 **서랍**입니다.

```
docs/done/           끝난 계획. 본문은 원문 그대로 두고 머리에 상자만 얹습니다
```

## 지금 어디까지 왔나

| 폴더 | 어디까지 | 남은 것 |
|---|---|---|
| [`2026-09/`](2026-09/) | 조사 → 판단 → 계획 → **구현 여섯 끝남** | 다섯이 관문·대기에 막혀 있습니다 |
| [`during-trip/`](during-trip/) | 조사 → 판단. **계획을 아직 안 썼습니다** | 받기로 한 다섯 |
| [`replan/`](replan/) | 조사 → 판단 → 계획. **구현 0** | 1차 넷이 바로 시작됩니다 |
| [`done/`](done/) | — | 여섯 |

폴더마다 `README.md` 가 그 안의 순서와 상태를 적어 둡니다. 이 문서는 폴더
사이만 봅니다.

## 다음에 손댈 것

막혀 있습니다** — 서버 0 · 스키마 0 · 구글 호출 0 · 새 의존 0 · 재빌드 0.

나머지 둘은 이렇습니다.

| 어디 | 무엇에 막혔나 |
|---|---|

## 폴더를 안 합치는 이유

한 폴더에 모으면 짧아 보이지만, `trip-feature` 가 정해 둔 것이 깨집니다 —
**각 단계는 앞 단계가 남긴 문서를 읽고 시작하고, 자기 문서를 남기고
끝납니다.** 조사 셋의 `survey.md` 를 한 파일에 합치면 어느 판정이 어느
조사의 것인지 알 수 없고, 그러면 "이건 그때 안 봤다" 를 말할 수 없게 됩니다.

세 조사가 같은 후보를 다르게 판정한 자리가 실제로 있습니다. 예를 들어
날씨는 `during-trip` 5번에서 **조건부 찬성**인데, `replan` 9번(비 오면 실내
대안)은 그것이 먼저 서야 해서 **계획을 아예 안 썼습니다.** 폴더가 갈려
있어서 그 의존을 적을 자리가 있습니다.

## 이름이 하나만 날짜인 이유

`during-trip`·`replan` 은 주제인데 `2026-09` 만 날짜입니다. 규칙이 그렇습니다
— **주제가 있으면 주제로, 없으면 `YYYY-MM` 으로.** 첫 조사는 "여행 앱이 요즘
뭘 하나" 를 통으로 본 것이라 주제가 없었습니다.

지금 와서 바꾸지 않습니다. 커밋 메시지와 문서 서른 곳이 그 이름을 가리키고
있고, 이름 하나 고르자고 그걸 전부 건드리는 것은 값이 안 맞습니다.

## 줄기 밖에 있는 것

[`ideas.md`](ideas.md) 는 조사가 아닙니다. **밖에서 본 것이 아니라 안에서
나온 것**입니다 — 쓰다가 아쉬웠던 자리를 적어 둔 목록이고, 판정은
`2026-09/verdict-ideas.md` 가 따로 했습니다. 그래서 `2026-09` 폴더에는
갈래가 둘입니다(`verdict.md` 와 `verdict-ideas.md`).
