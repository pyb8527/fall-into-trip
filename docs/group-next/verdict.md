## 먼저 짚을 것 — "이 여행에 가는 사람"이 지금 없습니다

| 쓰는 곳 | 하는 일 | 열두 명 모임에서 넷이 가는 여행이면 |

## 2. 참석 응답 — **찬성** (맨 먼저)

### 이미 있는 것
- 그룹 멤버: `group/domain/GroupMember.java`
- 여행이 사람을 묻는 문 하나: `TripAccessPolicy.peopleOf()`

### 붙는 자리
`TripController`(새 `PUT /api/trips/{id}/going`) → `src/app/trip/[id].tsx` 상단(함께하는 사람)과 `group/[id].tsx` 여행 줄

### 걸리는 것
없습니다. 오히려 **전원 동의 규칙을 바로 세웁니다.** 지금은 "전원"이 안 가는 사람까지 셉니다.

### 고쳐 받는다면
- 응답은 셋입니다. **갈게요 / 못 가요 / 아직 몰라요**. 한 줄 메모를 붙일 수 있고 모두에게 보입니다.
- `peopleOf()` 의 뜻을 바꿉니다. **만든 사람 + "못 가요"라고 하지 않은 멤버**입니다.
  "아직 몰라요"는 셈에 남습니다. 표 안 던진 사람을 미정으로 보는 지금 규칙과 같은 결입니다.
- **보는 권한은 바꾸지 않습니다.** "못 가요"라고 한 사람도 그룹 여행을 봅니다(`canRead` 그대로).
  셈에서만 빠집니다.
- 버리는 것:
  - 주최자만 보는 질문지(Partiful) — 알레르기 같은 것을 받아 두는 자리가 따로 생깁니다
  - 정원·대기열(Luma) — 모임은 닫혀 있습니다. 자리 다툼은 말로 합니다

### 값

| | |
|---|---|
| 새 외부 의존 | 없음 |
| 구글 호출 | 0 |
| 서버 저장 | 여행 × 멤버 한 줄 |
| EAS 재빌드 | 필요 없음 |
| 스키마 변경 | **있음** — `trip_going(trip_id, user_id, answer, note, updated_at)` (다음 번호 **V43** — V40 환율, V41 별점, V42 는 그 별점 칸의 타입을 고친 것입니다) |
| 백엔드 변경 | 새 엔드포인트 + **`peopleOf()` 수정** (쓰는 곳 다섯) |

### 지켜야 할 것
- `peopleOf()` 를 바꾸면 정산 숫자가 바뀝니다. **이미 적힌 지출의 정산이 옮겨 갑니다.**
  응답을 바꿀 때 "가계부 나눔이 바뀝니다"를 미리 보여 줍니다.
- "못 가요"로 바꾼 사람이 이미 낸 지출이 있으면 그 사람은 셈에서 빠지면 안 됩니다.
  **낸 사람과 나눌 사람으로 지정된 사람은 남깁니다.**
- 시험(`backend/src/test/http/`): "못 가요" 한 사람이 빠져도 나머지 전원 좋아요면 합의가 되는가, 정산이 몇 명에게 나뉘는가.

**네 명 모임에서 익명은 익명이 아닙니다.** 겹치는 구간만 보여 줘도 그 아래 끝이 가장 적게 부른 사람의 숫자입니다. 누구인지 짐작하는 데 오래 걸리지 않습니다. 「돈은 껄끄러움을 없애는 자리」인데, 이것은 적게 부른 사람을 찾는 놀이가 됩니다. 하는 앱도 찾지 못했습니다.
