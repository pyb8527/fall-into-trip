# 화면정의서 — 그룹

> 화면마다 **무엇에 답하는 자리인지**를 먼저 적습니다. 그것이 없으면 칸만
> 늘어납니다. 규칙과 데이터는 [`spec.md`](spec.md) 에 있습니다.

## 화면 목록

| 번호 | 이름 | 길 | 단계 |
|---|---|---|---|
| G-1 | 모임 목록 | `/(app)/groups` | 1 |
| G-2 | 모임 하나 | `/group/[id]` | 1 |
| G-3 | 모임 만들기 | 판 (G-1 안) | 1 |
| G-4 | 모임 초대 | 판 (G-2 안) | 1 |

| G-10 | 모임 사진첩 | G-2 안의 띠 | 4 |

## G-1. 모임 목록

**답하는 것**: 나는 어떤 무리에 속해 있나.

```
┌─────────────────────────────┐
│  모임                    [+] │   ← 고정 줄 (홈과 같은 꼴)
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 🍜  오사카 모임      5명 │ │
│ │     여행 3개 · 다음 11.08│ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ ⛰️  등산 크루        12명│ │
│ │     여행 1개              │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- 줄마다 **그림 · 이름 · 사람 수 · 여행 수 · 가장 가까운 여행**
- 「다음 11.08」 은 **그 모임에 다가오는 여행이 있을 때만**. 이게 이 화면을
  다시 열 이유가 됩니다
- 아무것도 없으면: 「아직 모임이 없어요. 같이 다니는 사람들이 있으면 만들어
  보세요.」 + 만들기 단추
- 줄 전체가 눌립니다 → G-2

**아래 띠에 칸이 하나 늡니다.** 지금 다섯(홈·내 여행·보석함·둘러보기·
가계부)에 「모임」이 더해져 여섯입니다.

> 여섯이면 좁은 폰에서 글자가 빡빡합니다. **가계부를 뺍니다** — 가계부는
> 여행 안에서 쓰는 것이고 이미 여행 띠에 있습니다. 바깥 띠에 있는 것은
> 「여행을 고르는 일의 절반」이라는 이유였는데, 모임 쪽이 그 자리를 더
> 잘 씁니다.

## G-2. 모임 하나

**답하는 것**: 이 무리는 지금 무엇을 하고 있나.

```
┌─────────────────────────────┐
│ ←  오사카 모임           ⋯  │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 🍜 오사카 모임            │ │
│ │ 1년에 한 번은 가자         │ │
│ │ 지영 민수 유정 +2    [초대]│ │
│ └─────────────────────────┘ │
│                             │
│ ╭───────╮                   │
│ │ 여행  │ 피드 │ 사진첩 │   │  ← 알약 띠
│ ╰───────╯                   │
│ ┌─────────────────────────┐ │
│ │ 다음 여행                 │ │
│ │ 오사카 3박 4일   11.08~  │ │
│ │ ───────────────────────  │ │
│ │ 지난 여행                 │ │
│ │ 교토 2박        작년 10월 │ │
│ │ 후쿠오카 당일     재작년   │ │
│ │                [여행 만들기]│ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- **머리 카드**: 그림·이름·소개·멤버 얼굴줄·초대 단추
  - 멤버 얼굴을 누르면 → G-9 (그 사람 프로필)
- **띠 셋**: 여행 / 피드 / 사진첩
  - 1단계에는 **여행만** 섭니다. 띠는 2단계에 생깁니다
- **여행 칸**: 다음 여행이 맨 위, 그 아래 지난 여행. 날짜 역순
  - 「다음 여행」은 **오늘 이후 날짜가 있는 것**
  - 누르면 그 여행의 일정 화면으로 (지금 그대로)
- **⋯** → G-5

> **왜 여행이 첫 칸인가** — 모임에 들어오는 이유가 대개 "다음에 언제 가지"
> 입니다. 피드를 먼저 두면 모임이 게시판처럼 읽히고, 그러면 카카오톡과
> 겹칩니다.

## G-3. 모임 만들기 (판)

**답하는 것**: 이 무리를 뭐라고 부를까.

```
┌─────────────────────────────┐
│ 모임 만들기               ✕ │
├─────────────────────────────┤
│ 그림     [🍜] 눌러서 고르기  │
│ 이름     [오사카 모임      ] │
│ 소개     [1년에 한 번은 가자]│
│          비워도 돼요          │
│                             │
│          [ 만들기 ]          │
└─────────────────────────────┘
```

- **이름만 있으면 됩니다.** 그림은 기본값이 있고 소개는 비워도 됩니다
- 만들면 바로 G-2 로 가고, **초대 판(G-4)이 이어서 열립니다** — 모임을
  혼자 쓰려고 만드는 사람은 없습니다

---

## G-4. 모임 초대 (판)

**답하는 것**: 어떻게 부르나.

```
┌─────────────────────────────┐
│ 오사카 모임에 부르기       ✕ │
├─────────────────────────────┤
│ 링크를 받은 사람만 들어와요.  │
│ 7일 뒤에 저절로 막혀요.       │
│                             │
│ ┌─────────────────────────┐ │
│ │ fit.../group-invite/a8k…│ │
│ └─────────────────────────┘ │
│   [ 링크 복사 ]  [ 보내기 ] │
└─────────────────────────────┘
```

- 여행 초대 판과 **같은 모양**입니다
- 「보내기」는 폰의 공유 창 (껍데기가 받습니다)

## G-5. 모임 설정 (판)

```
┌─────────────────────────────┐
│ 오사카 모임               ✕ │
├─────────────────────────────┤
│ ✏️  이름·소개 고치기     (주인)│
│ 👥  사람들                   │
│ 🔗  초대 링크 만들기          │
│ ──────────────────────────  │
│ 🚪  모임에서 나가기           │
│ 🗑️  모임 지우기          (주인)│
└─────────────────────────────┘
```

**「사람들」** 을 누르면 멤버 목록. 주인에게는 줄마다 「내보내기」가 붙습니다.

**「모임 지우기」** 를 누르면 묻습니다:

> 오사카 모임을 지울까요?
> 모임의 글과 사진이 사라져요. 되돌릴 수 없어요.
> **여행 3개는 안 지워져요** — 각자에게 그대로 남아요.

> 마지막 줄이 중요합니다. 이걸 안 적으면 여행까지 사라지는 줄 알고 아무도
> 못 지웁니다.

## G-6. 초대 받기

**답하는 것**: 이게 뭔데 들어가지.

```
┌─────────────────────────────┐
│          🍜                  │
│      오사카 모임             │
│   1년에 한 번은 가자          │
│                             │
│   지영 민수 유정 +2           │
│   여행 3개를 같이 다녔어요     │
│                             │
│      [ 들어가기 ]            │
│   계정이 없으면 만들고 들어가요│
└─────────────────────────────┘
```

- **로그인 없이 열립니다.** 무엇인지 보고 나서 가입을 정합니다
- 이미 멤버면 바로 G-2 로 보냅니다
- 만료됐으면: 「이 링크는 만료됐어요. 모임에 있는 사람에게 새로 받아 주세요.」

## G-7. 모임 피드 (G-2 안의 띠)

**답하는 것**: 그동안 무슨 일이 있었나.

```
│ 여행 │ ╭──────╮ │ 사진첩 │
│      │ │ 피드 │ │        │
├─────────────────────────────┤
│                   [글 쓰기] │
│ ┌─────────────────────────┐ │
│ │ 지영            2시간 전  │ │
│ │ ┌───────────────────────┐│ │
│ │ │   [사진 1/3]          ││ │
│ │ └───────────────────────┘│ │
│ │ 이번 오사카 진짜 좋았다…  │ │
│ │ 📍 오사카 3박 4일         │ │
│ │ 💬 3                      │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- **사진이 먼저, 글이 아래.** 여행 피드와 같은 규칙입니다
- 사진은 옆으로 넘깁니다(`PhotoStrip` 그대로)
- `📍` 은 **어느 여행 이야기인지**. 누르면 그 여행으로. 안 붙여도 됩니다
- `💬` 을 누르면 댓글 판

## G-8. 글 쓰기 (판)

```
┌─────────────────────────────┐
│ 오사카 모임에 올리기       ✕ │
├─────────────────────────────┤
│ [사진 고르기 (10장까지)]     │
│                             │
│ ┌─────────────────────────┐ │
│ │ 무슨 일이 있었나요?       │ │
│ │                          │ │
│ └─────────────────────────┘ │
│                             │
│ 어느 여행? [오사카 3박 ▾]    │
│            안 골라도 돼요     │
│                             │
│          [ 올리기 ]          │
└─────────────────────────────┘
```

- **사진만 올려도 됩니다.** 글만 써도 됩니다. 둘 다 비면 못 올립니다
- 「어느 여행」은 **그 모임의 여행**만 나옵니다

## G-9. 마이페이지

**답하는 것**: 내가(또는 저 사람이) 어떤 여행을 해 왔나.

```
┌─────────────────────────────┐
│ ┌─────────────────────────┐ │
│ │      🙂                  │ │
│ │     지영                 │ │
│ │  2026년 3월부터           │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │  여행 7   올린 글 2       │ │
│ │  다녀온 곳 94  사진 213   │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 속한 모임                 │ │
│ │ 🍜 오사카 모임            │ │
│ │ ⛰️ 등산 크루              │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 올린 여행기               │ │
│ │ 오사카 3박 4일      ♥ 12 │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 내 계정                   │ │  ← 내 것일 때만
│ │ 알림 · 비밀번호 · 로그아웃 │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- **내 것**과 **남의 것**이 같은 화면입니다. 내 것에만 「내 계정」 칸이 붙습니다
- 남의 것은 **같은 그룹 사람에게만** 열립니다
- 지금 「내 계정」 화면의 내용(알림·지도에서 나·비밀번호·로그아웃)은 맨 아래
  칸으로 들어갑니다

> **숫자를 먼저 두는 이유** — 「여행 7, 다녀온 곳 94」 는 이 앱을 쓴 흔적이고,
> 그걸 보는 것이 다시 쓸 이유가 됩니다. 모임에서 남의 이름을 눌렀을 때
> 「이 사람 많이 다녔네」 가 바로 보여야 합니다.

## G-10. 모임 사진첩 (4단계)

**답하는 것**: 그때 그 사진 어디 있지.

```
│ 여행 │ 피드 │ ╭────────╮
│      │      │ │ 사진첩 │
├─────────────────────────────┤
│                   [사진 넣기]│
│ 오사카 3박 4일        2026.11│
│ ┌───┬───┬───┐               │
│ │   │   │   │               │
│ ├───┼───┼───┤               │
│ │   │   │   │               │
│ └───┴───┴───┘               │
│ 교토 2박             2025.10 │
│ ┌───┬───┬───┐               │
└─────────────────────────────┘
```

- **여행별로 묶습니다.** 「그때 그 사진」을 찾을 때 기준이 여행입니다
- 여행에 안 붙은 것은 맨 아래 「그 밖에」
- 누르면 크게 보기(`PhotoViewer` 그대로)

## 기존 화면에 생기는 변화

| 화면 | 무엇이 |
|---|---|
| **아래 갈래 띠** | 「가계부」를 빼고 「모임」을 넣습니다 |
| **내 여행 목록** | 그룹 여행에 작은 그룹 이름표 (`🍜 오사카 모임`) |
| **여행 만들기** | 「어느 모임?」 칸 하나. 안 골라도 됩니다 |
| **여행 상세 ⋯** | 「모임에 넣기 / 빼기」 |
| **내 계정** | G-9 로 커집니다. 길도 `/(app)/settings` → `/(app)/me` |
| **소식함** | 그룹 소식 셋이 섞여 들어옵니다 |

## 화면 사이

```
         아래 띠
            │
        [모임] G-1 ──┬── [+] ──> G-3 ──> G-4
            │        │
            └──> G-2 ┼── ⋯ ──> G-5
                     ├── 띠 ──> G-7 ──> G-8
                     ├── 띠 ──> G-10
                     ├── 멤버 ──> G-9
                     └── 여행 ──> 일정 화면 (기존)

   링크 ──> G-6 ──> G-2
```
