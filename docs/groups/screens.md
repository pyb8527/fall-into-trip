# 화면정의서 — 그룹 · 피드 · 리뷰

> 화면마다 **무엇에 답하는 자리인지**를 먼저 적습니다. 규칙과 데이터는
> [`spec.md`](spec.md) 에 있습니다.

## 아래 갈래 띠 — 먼저 정해야 합니다

지금 다섯입니다: 홈 · 내 여행 · 보석함 · 둘러보기 · 가계부.
여기에 **모임**과 **피드**가 들어와야 하는데, 일곱은 좁은 폰에서 못 섭니다.

**제안**

```
홈 · 모임 · 내 여행 · 보석함 · 둘러보기
```

- **가계부를 뺍니다** — 여행 안에서 쓰는 것이고 이미 여행 띠에 있습니다
- **피드는 칸을 안 받습니다** — 그룹 안(그룹 피드)과 마이페이지(내 피드)에
  살고, 둘 다 들어가는 길이 이미 있습니다

> 피드에 칸을 주면 「어느 피드인가」를 그 화면이 또 물어야 합니다. 그룹에
> 들어가서 보는 것이 더 자연스럽습니다.

## G-1. 모임 목록

**답하는 것**: 나는 어떤 무리에 속해 있나.

```
┌─────────────────────────────┐
│  모임                    [+] │  ← 고정 줄
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 🍜  오사카 모임      5명 │ │
│ │     여행 3개 · 다음 11.08│ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ ⛰️  등산 크루       12명 │ │
│ │     여행 1개              │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- 「다음 11.08」 은 **다가오는 여행이 있을 때만**. 이게 다시 열 이유입니다
- 비었으면: 「같이 다니는 사람들이 있으면 모임을 만들어 보세요. 여행은
  모임 안에서 만들어요.」

---

## G-2. 모임 하나

**답하는 것**: 이 무리는 지금 무엇을 하고 있나.

```
┌─────────────────────────────┐
│ ←  오사카 모임           ⋯  │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 🍜 오사카 모임            │ │
│ │ 1년에 한 번은 가자         │ │
│ │ 지영 민수 유정 +2   [초대] │ │
│ └─────────────────────────┘ │
│ ╭───────╮                   │
│ │ 여행  │ 피드 │            │  ← 알약 띠
│ ╰───────╯                   │
│ ┌─────────────────────────┐ │
│ │ 다음 여행                 │ │
│ │ 오사카 3박 4일   11.08~  │ │
│ │ ───────────────────────  │ │
│ │ 지난 여행                 │ │
│ │ 교토 2박        작년 10월 │ │
│ │              [여행 만들기] │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- 멤버 얼굴을 누르면 → G-10
- **여행이 첫 칸입니다.** 모임에 들어오는 이유가 대개 "다음에 언제 가지"
  입니다. 피드를 먼저 두면 모임이 게시판처럼 읽히고 카카오톡과 겹칩니다

---

## G-3. 모임 만들기 (판)

```
┌─────────────────────────────┐
│ 모임 만들기               ✕ │
├─────────────────────────────┤
│ 그림  [🍜]                   │
│ 이름  [오사카 모임         ] │
│ 소개  [비워도 돼요         ] │
│          [ 만들기 ]          │
└─────────────────────────────┘
```

**이름 하나면 됩니다.** 가벼워야 하는 이유가 분명합니다 — 여행 멤버를
없앴으므로 「이번 여행만 같이 짜는 동료」에게도 그룹을 만들어야 합니다.

만들면 **초대 판(G-4)이 이어서 열립니다.**

## G-4. 모임 초대 (판)

```
┌─────────────────────────────┐
│ 오사카 모임에 부르기       ✕ │
├─────────────────────────────┤
│ 링크를 받은 사람만 들어와요.  │
│ 7일 뒤에 저절로 막혀요.       │
│ ┌─────────────────────────┐ │
│ │ fit.../group-invite/a8k…│ │
│ └─────────────────────────┘ │
│   [ 링크 복사 ]  [ 보내기 ] │
└─────────────────────────────┘
```

지금 여행 초대 판을 그대로 옮깁니다.

## G-5. 모임 설정 (판)

```
│ ✏️  이름·소개 고치기    (주인) │
│ 👥  사람들                    │
│ 🔗  초대 링크 만들기           │
│ ───────────────────────────  │
│ 🚪  모임에서 나가기            │
│ 🗑️  모임 지우기         (주인) │
```

지울 때 묻습니다:

> 오사카 모임을 지울까요?
> 모임의 글과 사진이 사라져요. 되돌릴 수 없어요.
> **여행 3개는 안 지워져요** — 만든 사람에게 그대로 남아요.

## G-6. 초대 받기

```
┌─────────────────────────────┐
│          🍜                  │
│      오사카 모임             │
│   1년에 한 번은 가자          │
│   지영 민수 유정 +2           │
│   여행 3개를 같이 다녔어요     │
│      [ 들어가기 ]            │
│  계정이 없으면 만들고 들어가요 │
└─────────────────────────────┘
```

**로그인 없이 열립니다.** 무엇인지 보고 나서 가입을 정합니다.

## G-7. 내 여행 — 탭 둘

**답하는 것**: 내가 짠 여행과 모임에서 짠 여행.

```
┌─────────────────────────────┐
│ ╭────────╮                  │
│ │ 내 여행 │ 모임 여행 │     │
│ ╰────────╯                  │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 제주 혼자               │ │
│ │ 3박 4일 · 다음 주        │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

「모임 여행」 칸에서는 줄마다 **모임 이름표**가 붙습니다(`🍜 오사카 모임`).

> 지금 있는 「언제로 묶기 / 폴더로 묶기」 띠는 **각 탭 안에서** 그대로
> 씁니다. 띠가 둘이 되지만, 바깥 띠는 「누구 것이냐」이고 안쪽 띠는
> 「어떻게 묶을까」라 묻는 것이 다릅니다.

---

## G-8. 피드 (G-2 안의 띠, 그리고 마이페이지 안)

**답하는 것**: 그동안 무슨 일이 있었나.

```
│ 여행 │ ╭──────╮
│      │ │ 피드 │
├─────────────────────────────┤
│                   [글 쓰기] │
│ ┌─────────────────────────┐ │
│ │ 🙂 지영         2시간 전 │ │
│ │ ┌───────────────────────┐│ │
│ │ │     [사진 1/3]        ││ │
│ │ └───────────────────────┘│ │
│ │ 이번 오사카 진짜 좋았다…  │ │
│ │ #오사카 #라멘             │ │
│ │ 📍 오사카 3박 4일         │ │
│ │ 💬 3                      │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- **사진이 먼저, 글이 아래, 태그가 그 아래.** 인스타와 같은 차례
- 사진은 옆으로 넘깁니다(`PhotoStrip` 그대로)
- **좋아요 없음.** 댓글만
- `📍` 는 어느 여행 이야기인지. 누르면 그 여행으로
- 태그를 누르면 **그 태그가 달린 글만** 봅니다

---

## G-9. 글 쓰기 (판)

```
┌─────────────────────────────┐
│ 오사카 모임에 올리기       ✕ │
├─────────────────────────────┤
│ [사진 고르기 (10장까지)]     │
│ ┌─────────────────────────┐ │
│ │ 무슨 일이 있었나요?       │ │
│ └─────────────────────────┘ │
│ 태그  [#오사카] [#라멘] [+]  │
│ 여행  [오사카 3박 ▾] 안 골라도│
│          [ 올리기 ]          │
└─────────────────────────────┘
```

- **사진만 올려도, 글만 써도 됩니다.** 둘 다 비면 못 올립니다
- 「여행」 은 그 모임의 여행만 나옵니다
- 내 피드에서 쓰면 제목이 「내 피드에 올리기」, 여행은 내 여행만

---

## G-10. 마이페이지

**답하는 것**: 내가(저 사람이) 어떤 여행을 해 왔나.

```
┌─────────────────────────────┐
│ ┌─────────────────────────┐ │
│ │      🙂   지영           │ │
│ │   2026년 3월부터          │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 여행 7   글 23           │ │
│ │ 리뷰 11  사진 213         │ │
│ └─────────────────────────┘ │
│ ╭────────╮                  │
│ │ 내 피드 │ 모임 │ 여행기 │ │
│ ╰────────╯                  │
│ ┌─────────────────────────┐ │
│ │ (피드 글들)               │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 내 계정                   │ │  ← 내 것일 때만
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- **내 것과 남의 것이 같은 화면.** 내 것에만 「내 계정」이 붙습니다
- 남의 것은 **같은 그룹 사람에게만**
- **내 피드가 여기 삽니다** — 그룹 없이 올린 글

---

## G-11. 장소 리뷰 (장소 상세 판 안)

**답하는 것**: 남들은 여기 어떻게 봤나.

```
┌─────────────────────────────┐
│ 이치란 도톤보리점         ✕ │
├─────────────────────────────┤
│ [사진]                       │
│ [지도 그림]                  │
│ ★ 4.2 (구글 8,231)           │
│ ★ 4.6 · 우리 11명            │  ← 새로
│ ───────────────────────────  │
│ 남긴 한 줄                    │
│ 🙂 지영  ★★★★★             │
│    2번 출구로 나와야 함       │
│ 🙂 민수  ★★★★               │
│    대기 40분                 │
│            [ 나도 남기기 ]   │
└─────────────────────────────┘
```

- 구글 평점과 **우리 평점**을 나란히 둡니다. 다르면 그게 정보입니다
- 남기기 판: **별 다섯 + 한 줄**. 둘 중 하나만 써도 됩니다

> 이게 쌓이면 **「지금 뜨는 여행지」 랭킹**과 **추천**의 재료가 됩니다 —
> 지금은 "몇 개의 여행에 담겼나" 만으로 세는데, 거기에 "가 본 사람들이
> 어떻게 봤나" 가 더해집니다.

## 기존 화면에 생기는 변화

| 화면 | 무엇이 |
|---|---|
| **아래 띠** | 가계부를 빼고 모임을 넣습니다 |
| **여행 피드**(`travel/[id]`) | **없어집니다** |
| **여행 상세** | 도장·진행률·장소 기록이 빠집니다. 「챙겨 둔 것」은 남습니다 |
| **여행 상세 ⋯** | 「모임에 넣기/빼기」. 「동행자」는 없어집니다 |
| **내 여행** | 탭 둘 (G-7) |
| **여행 만들기** | 「어느 모임?」 칸. 안 골라도 됩니다 |
| **여행기 올리기** | 「어떤 글을 같이 실을까요」 — 그 여행의 피드 글을 고릅니다 |
| **둘러보기 여행기** | 장소 기록 대신 **고른 피드 글**이 실립니다 |
| **내 계정** | G-10 으로 커집니다 |
| **장소 상세 판** | 리뷰 칸 (G-11) |
| **보석함** | 「다녀옴」 표시가 빠집니다 |

## 화면 사이

```
      아래 띠
         │
   [모임] G-1 ──┬── [+] ──> G-3 ──> G-4
         │      │
         │      └──> G-2 ┬── ⋯ ──> G-5
         │               ├── 띠 ──> G-8 ──> G-9
         │               ├── 멤버 ──> G-10
         │               └── 여행 ──> 일정 (기존)
         │
 [내 여행] G-7 ──> 일정 (기존)
         │
   [홈] ──> ⚙ ──> G-10 ──> 띠 ──> G-8(내 피드)

   링크 ──> G-6 ──> G-2
   일정 ──> 장소 누르기 ──> 장소 상세 판 ──> G-11
```
