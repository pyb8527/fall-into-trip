## 4. 실측 — 무엇을 재나

**만들 것**: 개발용 숨은 단추 하나(요약 동선 탭, 개발 빌드에서만). 누르면:
1. Maps JS 를 부르기 **전에** `HTMLCanvasElement.prototype.getContext` 를 감싸 WebGL 에 `preserveDrawingBuffer: true` 를 넣음(2차 출처의 방법, `survey.md` 4)
2. 재생을 처음부터 돌리며 지도 캔버스를 `captureStream(30)` → `MediaRecorder`
3. 10초 뒤 멈추고 `Blob` 을 base64 로 → 껍데기 `saveFile`(UTI 를 MIME 에 따라 고르게 고친 판) → 공유 시트

**잴 기기**

| 기기 | 웹뷰 |
|---|---|
| iPhone (iOS 최신) | WKWebView |
| iPhone (iOS 한 판 아래) | WKWebView |
| 중급 안드로이드 | Android System WebView |
| 저사양 안드로이드 | 같음 |
| 데스크톱 크롬 · 사파리 | 비교용 |

**기기마다 적을 것**

| 항목 | 통과 기준 |
|---|---|
| `captureStream` 이 있는가 | 있음 |
| `MediaRecorder` 가 만드는 형식 | iOS mp4, 안드로이드 webm 또는 mp4 |
| 영상에 **지도와 3D 탈것이 함께** 찍히는가 | 찍힘 |
| 들른 곳 점 · 노선 이름 알약(DOM)은 | 안 찍힐 것으로 예상 — 기록만 |
| **구글 로고 · 저작권 표시**가 영상 안에 있는가 | 있어야 함(지오 가이드라인) |
| 녹화 중 프레임 | 눈으로 끊기지 않음 |
| 10초 파일 크기 | 기록 |
| 공유 시트로 넘어가 인스타 · 카톡에 붙는가 | 붙음 |

**통과** = iOS 한 대 이상 + 안드로이드 중급 한 대 이상에서 위 "있어야 함"이 다 맞음.
