## 9. 일본 노선 모양 — **조건부 찬성** (1차, 이번의 핵심)

### 이미 있는 것
- 탈것이 선을 따라가는 길: `journey.travel(from, to)` 의 `from.path`(`docs/plan-trip-3d.md`). **선만 넘겨 주면 됩니다.**
- 일본에서 구글이 대중교통을 안 준다는 안내: `RouteService.java:279-305`
- 사람이 적는 경유: `Move.via` (`api/types.ts:125`). "긴자선"을 적을 자리가 이미 있습니다.

### 붙는 자리
새 `lib/rail-jp.ts` → `journey.travel` 에 넘기는 `path` 를 고르는 자리(`trip-map-3d.web.tsx:111`, 요약 재생은 1번과 함께)

### 걸리는 것
- **아는 것만 말합니다** — 시각표가 없으니 "14:32 출발"은 못 냅니다. 노선 모양은 **대략의 경로**입니다(환승역·급행 여부가 실제와 다를 수 있음). 화면에 그렇게 밝힙니다.
- **자유 글자를 숫자로 읽지 않습니다** — `via` 는 사람이 적은 글입니다. 노선 이름을 고를 때 쓰되 **N02 노선명과 정확히 같을 때만** 그 노선으로 묶고, 아니면 무시합니다.

### 고쳐 받는다면
1. **데이터** — 국토교통성 N02 GeoJSON 을 미리 가공해 `public/rail/` 에 둡니다.
   - 도쿄권 · 오사카권 · 교토 · 후쿠오카 등 여행지 범위만 잘라 지역별 파일로 나눕니다.
   - 노선 선을 이어 **역–역 그래프**로 만들어 둡니다(가공 스크립트는 `scripts/` 에).
   - 앱은 **일본 여행에서 3D·재생을 켤 때만** 그 지역 파일을 받습니다.
2. **경로 고르기** — 대중교통으로 갈 구간(적어 둔 수단이 전철·지하철, 또는 구글 대중교통이 비고 2km 넘는 구간)이면:
   - 출발 · 도착 장소에서 가까운 역을 찾습니다(걸을 만한 거리 안).
   - 그래프에서 최단 경로를 구하고, 그 선을 `path` 로 넘깁니다.
   - 장소 → 역, 역 → 장소는 걷기로 잇습니다.
   - 역을 못 찾으면 **지금처럼 곧게** 갑니다.
3. **노선 이름** — 한 노선으로만 간 경로면 "긴자선" 같은 이름을 띄웁니다. 갈아탔으면 노선들을 차례로. 시각·분은 **사람이 적은 `Move.min` 만** 씁니다.

## 1. 실제 길 따라가기 — 여행 상세는 **이미 있음**, 요약 재생은 **조건부 찬성** (3차)

  - 지금 이동 시간 응답은 캐시에 없으면 구글을 부릅니다. 그래서 **"캐시에 있을 때만 돌려주고 없으면 비워서"** 답하는 갈래가 하나 필요합니다.

- 일본 대중교통 구간은 9번의 노선 선을 씁니다 — **끝난 여행에도 늘 있습니다**(정적 파일).

## 8. deck.gl TripsLayer — **반대**

## 10. ODPT — **반대** (지금은)

**노선 모양은 9번(N02)이 줍니다.** ODPT 가 더 주는 것은 시각표 · 실시간 위치인데, 이번에는 그 둘이 필요 없습니다.
게다가 노선마다 라이선스가 다르고, "ODPT 기본 라이선스" 노선은 **재배포에 제한**이 있어 `public/` 에 실어 내보낼 수 없습니다. 시각까지 하자고 하면 그때 11번과 함께 다시 봅니다.

## 11. NAVITIME API — **반대** (지금은)

**시각과 노선 모양을 한 번에 주는 유일한 곳**입니다. 하지만:
- 무료 등급의 호출 한도, 응답 저장 약관, 구글 지도 위에 그려도 되는지를 모릅니다.
- 유료 등급이 월 $200 부터입니다.
- 구글처럼 서버 하나의 문 뒤에 두고 호출을 세는 일(`GoogleQuotaFilter` 와 같은 것)이 새로 생깁니다.

지금 시각은 **사람이 적은 `Move.min`** 으로 충분합니다. "출발 시각까지 앱이 알아야 한다"는 요구가 생기면 이것부터 다시 봅니다.

## 12. 駅すぱあと API — **반대**

무료 플랜은 "확인용 URL"만 주고, 노선도 모양(shape)은 **노선도 그림 위의 X·Y 좌표**로 보입니다(지리 좌표인지 확인 못 함). 지도에 그릴 선이 안 나올 가능성이 큽니다.
