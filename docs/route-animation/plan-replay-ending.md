**지금 안 되는 것**

**지금 사람이 어떻게 우회하나** — 피드나 모임에 들어가 이 여행의 글을 따로 찾아봅니다.

## 3. 버리는 것

- **재생 중 찍은 자리에 사진 띄우기** — 올린 사진의 GPS 를 지웁니다(`PhotoService.java`). 피드 글에 날짜도 안 붙습니다.
- **실제로 움직인 거리** — 위치 기록을 안 남깁니다(house-rules). "장소 사이 거리"만 셉니다.
- **영상 끝 화면으로 쓰기** — `plan-video-spike.md` 가 서면 그때 붙입니다.

## 5. 닿는 파일

| 파일 | 바뀌는 것 |
|---|---|
| `frontend/src/components/replay-stage.web.tsx` | `onDone` 콜백을 받아 `done` 에서 부름 |
| `frontend/src/components/replay-ending.tsx` | **새로** — 통계 줄 + 사진 줄 + 버튼 둘 |
| `frontend/src/app/card/[id].tsx` | `onDone` 이면 `ReplayEnding` 을 보임. 통계 재료는 이미 받은 여행 · 정산에서 |
| `frontend/src/components/trip-album.tsx` | 첫 줄만 보여 주는 `limit` 받기(없으면 지금처럼) |

**통계 셈**
- 며칠: `trip.days.length`
- 장소: 일정 장소 수
- 장소 사이 거리: 날짜마다 차례대로 `distanceKm` 의 합. 소수 없이 km. 1km 미만이면 m.
- 쓴 돈: 가계부 화면과 **같은 함수**를 꺼내 씁니다(원화 합계는 환율이 있는 통화만, 나머지는 나란히). 지출이 없으면 줄을 안 그림.
