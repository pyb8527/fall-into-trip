# 구글 플레이 제출 — 답안지와 할 일

> 2026-10-07. 스토어 준비 5단계(docs/plan-store-readiness.md)의 구글 몫입니다.
> Play Console 에 적을 답을 미리 정리해 두었습니다. 앱이 바뀌면 이 표도 같이
> 고칩니다.

## 1. 데이터 보안(Data safety) 양식 답

### 기본 질문

| 질문 | 답 | 근거 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | 예 | 계정 · 일정 · 사진 · 위치 |
| 전송 중 데이터가 암호화되나요? | 예 | 모든 통신 HTTPS(Cloudflare 터널) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예 | 앱 설정 › 회원 탈퇴, 웹 `/account/delete` |
| 계정 삭제 URL | `https://fit.weenie-beenie.net/account/delete` | 앱을 지운 사람도 쓸 수 있는 웹 페이지 |
| 개인정보처리방침 URL | `https://fit.weenie-beenie.net/privacy` | |

### 수집하는 데이터(구글 분류 기준)

「공유」는 구글 정의상 **제3자에게 넘기는 것**입니다. 사용자가 직접 동행자에게
보이게 하는 것(위치 알리기, 같이 보는 일정)은 사용자가 시작한 전송이라 공유에
넣지 않습니다. 처리 위탁(구글 지도 · 카카오 로그인 · Expo 푸시)도 공유가
아닙니다.

| 분류 | 항목 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|---|
| 위치 | 정확한 위치 | 예 | 아니요 | 선택 | 앱 기능(지도에 내 위치, 동행자에게 위치 알리기) |
| 위치 | 대략적 위치 | 예 | 아니요 | 선택 | 같음 |
| 개인 정보 | 이름 | 예 | 아니요 | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 | 이메일 주소 | 예 | 아니요 | 필수 | 계정 관리 |
| 개인 정보 | 사용자 ID | 예 | 아니요 | 필수 | 계정 관리(구글 · 카카오 회원 식별값) |
| 사진 및 동영상 | 사진 | 예 | 아니요 | 선택 | 앱 기능(여행 사진 · 프로필) |
| 앱 활동 | 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 선택 | 앱 기능(일정 · 글 · 댓글 · 별점 · 가계부) |
| 금융 정보 | 기타 금융 정보 | 예 | 아니요 | 선택 | 앱 기능(가계부에 적은 금액 — 결제 정보 아님) |
| 기기 또는 기타 ID | 기기 ID | 예 | 아니요 | 선택 | 앱 기능(푸시 알림 토큰) |

- 「데이터가 일시적으로만 처리되나요?」 — 위치: **아니요**(위치 알리기는 최대
  4시간 저장). 지도에 내 위치만 볼 때는 서버에 저장하지 않지만, 한 항목에 한
  답만 고를 수 있어 보수적으로 아니요.
- 광고 · 분석 · 사기 방지 목적: 해당 없음(광고 · 분석 SDK 없음).
- 수집하지 않는 것: 연락처, 캘린더(쓰기만 하고 읽지 않음), 오디오, 건강, 검색
  기록(장소 검색어는 구글로 보내지만 우리는 저장하지 않음), 웹 기록, 앱 정보 ·
  성능(크래시 로그 수집 도구 없음).

## 2. 앱 액세스(심사용 계정) — 영어로

Play Console › 앱 콘텐츠 › 앱 액세스 › 「일부 기능이 제한됨」에 넣습니다.

```
Name: Demo account (email login)
Username: <심사용 계정 이메일>
Password: <심사용 계정 비밀번호>
Instructions:
1. Open the app, enter the email ("이메일") and password ("비밀번호") above and
   tap "로그인" (Log in). No OTP or 2-step verification is required.
2. The account already has a sample trip "Tokyo trip" with places, a budget
   ("가계부"), a packing list ("챙길 것") and a vote ("가고 싶은 곳").
3. Community/feed: bottom tab "둘러보기" (Explore). Each post and profile has
   a "신고" (Report) and "차단" (Block) action in its menu.
4. Account deletion: Settings (톱니바퀴) > "회원 탈퇴". Web:
   https://fit.weenie-beenie.net/account/delete
5. Location is optional and only requested when the user taps the location
   button or turns on "지금 여기" / location sharing on a trip.
```

심사용 계정은 **아무 실제 사람과도 이어지지 않게** 새로 만들고, 동행자 역할의
두 번째 심사용 계정을 하나 더 만들어 같은 여행에 넣어 둡니다(정산 · 위치 알리기를
보여 주려면 두 사람이 필요합니다).

## 3. 콘텐츠 등급 질문지(IARC) 답 방향

| 질문 | 답 |
|---|---|
| 앱 분류 | 참고서 · 뉴스 · 교육이 아닌 일반 앱(여행 · 지역 정보) |
| 폭력 · 성적 콘텐츠 · 비속어 · 마약 · 도박 | 없음 |
| 사용자 간 소통(글 · 댓글 · 프로필) | **있음** |
| 사용자 생성 콘텐츠 공유 | **있음** — 신고 · 차단 · 걸러내기 있음 |
| 사용자 위치를 다른 사용자와 공유 | **있음** — 직접 켰을 때 그 여행 동행자에게만 |
| 디지털 상품 구매 | 없음 |

## 4. 그 밖의 Play Console 항목

| 항목 | 답 |
|---|---|
| 광고 포함 | 아니요 |
| 타깃 연령 | 만 18세 이상(13~17 포함하면 가족 정책 심사가 붙음 — 가입은 만 14세 이상이지만 타깃층은 성인으로 둠) |
| 정부 앱 · 금융 기능 · 건강 | 해당 없음 |
| 뉴스 앱 | 아니요 |
| 위치 권한 | 포그라운드만 — 백그라운드 위치 신고서 필요 없음 |
| 사진 · 동영상 권한 | 쓰지 않음(시스템 사진 선택기) — 신고서 필요 없음 |

## 5. 사람이 할 일 (순서대로)

1. **문의 이메일** 정하기 → 처리방침 · 약관 · 탈퇴 페이지의 노란 칸과 함께 채움
2. 처리방침 · 약관의 노란 칸 채우기: 운영자 이름, 서버 위치, 운영 기록 보관 기간,
   주소, 위치기반서비스사업 신고 번호
3. **위치기반서비스사업 신고**(방송미디어통신위원회) — 소상공인 · 1인 창조기업
   특례에 해당하면 서비스 시작 후 1개월 안에. 해당 여부는 방미통위 · KISA
   위치정보지원센터에 문의
4. Play Console: 개발자 인증 · 앱 등록 확인(2026-09-30 마감 지남 — 미등록이면
   앱이 내려감)
5. 심사용 계정 두 개 만들고 예시 여행 채우기
6. **비공개 테스트 12명 × 14일 연속**(2023-11-13 이후 만든 개인 계정) — 테스터
   모으기 → 비공개 트랙에 올리기 → 14일 뒤 프로덕션 신청
7. 위 표대로 Data safety · 콘텐츠 등급 · 앱 액세스 · 광고 · 타깃 연령 작성
8. 스토어 등록정보: 앱 이름 · 짧은 설명 · 자세한 설명 · 스크린샷(폰 2장 이상) ·
   기능 그래픽(1024×500). 소개 페이지(/info)의 문구와 화면을 그대로 써도 됨
