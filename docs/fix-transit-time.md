# 대중교통만 안 나오던 것

> 쓰다가 나온 고장입니다. 조사에서 나온 것이 아닙니다.
>
> **한 가지를 고쳤습니다.** 나머지 둘은 아직 사람이 봐야 압니다 — §4.

## 1. 무엇이 보였나

걷기와 차는 나오는데 **대중교통만 안 나오는 구간**이 있었습니다. 같은 구간을
구글 지도 앱에서 찾으면 나옵니다.

## 2. 확실한 원인 — 언제 타는지를 안 보냈습니다

`RouteService.ask()` 가 구글에 보내는 몸통에 `departureTime` 이 없었습니다.

구글 문서가 이렇게 적어 두었습니다.

> 둘 다 안 주면 `departure_time` 은 **현재 시각(now)** 으로 기본값이 잡힙니다.

그래서 **11월 일정을 새벽 두 시에 짜면 그 시각 시각표로 계산**했습니다. 그때
안 다니는 노선은 "그런 길 없음" 으로 왔습니다.

**걷기와 차는 시각표가 없습니다.** 그래서 멀쩡히 나왔고, 대중교통만 빠진
것처럼 보였습니다.

그런데 `of()` 는 **`day.getIso()` 를 이미 들고 있었습니다.** 날짜를 아는데
안 보내고 있었습니다.

## 3. 고친 것

### 3.1 그 날 그 시각으로 묻습니다

`departureFor(day, from)` 이 정합니다.

| | |
|---|---|
| 날짜 | `Day.iso` |
| 시각 | 출발하는 장소에 적어 둔 `time`. 못 읽으면 **09:00** |
| 시간대 | **경도 ÷ 15** 로 어림 |

**"점심때쯤" 은 시각으로 안 읽습니다.** 집 규칙이 자유 글자를 숫자로 읽지
말라고 합니다. 그런 자리는 낮으로 둡니다.

### 3.2 시간대를 왜 어림하는가

구글에게는 **절대 시각**을 줘야 하는데 우리는 그 나라의 시간대를 모릅니다.
좌표로 사 오는 길(Time Zone API)이 있지만 **바깥문을 하나 더 여는 일**입니다.

그래서 경도로 어림합니다. 오사카(135도)는 +9로 정확히 맞고 유럽은 한두
시간 틀립니다. **틀려도 됩니다** — 고치려는 것은 "낮에 다니는 것을 밤으로
물어서 아무것도 안 나오는 것" 이지 분 단위 정확도가 아닙니다.

### 3.3 구글이 받는 창

지금부터 **7일 전 ~ 100일 뒤**까지만 받습니다. 그 밖이면 **아예 안
보냅니다** — 보내면 요청이 거절돼서 지금보다 나빠집니다. 아주 먼 여행은
예전처럼 현재 시각으로 계산되고, 그건 원래 하던 대로입니다.

경계에서 미끄러지지 않게 5일 / 95일로 줄여 잡았습니다.

### 3.4 캐시 열쇠에 시각을 넣었습니다

**이걸 빠뜨리면 고친 것이 도리어 해가 됩니다.** 열쇠가 `(수단, 좌표, 좌표)`
뿐이라, 11월 1일 아침과 11월 3일 밤이 같은 칸을 쓰고 먼저 물은 쪽의 답이
다른 날에도 나옵니다.

### 3.5 안 건드린 것

| | 왜 |
|---|---|
| 걷기·차 | 시각표가 없습니다. 차에 붙이면 그 시각의 교통량으로 계산이 바뀌는데, 이 결함과 상관없는 다른 변화입니다 |
| "지금 여기서"(`fromHere`) | 정말 지금입니다. 구글이 현재로 잡는 것이 맞습니다 |
| 길 위에서 찾기(`pathBetween`) | 길 모양만 씁니다. 걷기로 묻고 있어 시각이 상관없습니다 |

## 4. 아직 사람이 봐야 하는 것

이것을 고쳐도 안 나오면 남은 둘 중 하나입니다.

| | |
|---|---|
| **두 곳이 너무 가까움** | 몇백 미터면 구글이 버스를 태울 이유가 없다고 봅니다. 정상입니다 |
| **지역** | 구글이 *"Functionality varies by region"* 이라고만 하고 어느 나라가 되는지는 안 밝힙니다. **여기는 단정 못 합니다** |

### 어느 것인지 아는 법

코드가 이미 이유를 남깁니다(`ask()` 의 `log.info`).

```bash
docker compose logs api | grep "경로가 비었습니다"
```

`응답=` 안이 빈 `{}` 면 거리나 지역이고, 오류 메시지가 있으면 다른 문제입니다.

## 5. 잰 것

`DepartureTimeTest` **7 통과 / 0 실패** (새로). 구글 키가 없어도 이 셈은
잽니다 — 보는 것이 "무엇을 물어보는가" 이기 때문입니다.

| 무엇을 | |
|---|---|
| 적어 둔 시각을 그 날짜에 붙이는가 | 12:30 현지 = 03:30 UTC (동경 135도) |
| 자유 글자를 시각으로 안 읽는가 | "점심때쯤" → 09:00 |
| 시간대를 경도로 어림하는가 | 런던이 오사카보다 아홉 시간 늦게 아침 |
| 창 밖이면 안 보내는가 | 200일 뒤, 60일 전 → `null` |
| **창 안이면 반드시 보내는가** | 여기서 `null` 이면 고친 것이 아무 일도 안 합니다 |

같이 돌린 것 — `./gradlew test` 34 통과(신규 7), icon 42 · trip 60 ·
recommend 30 · place 9, 전부 0 실패.

**실제로 노선이 나오는지는 못 쟀습니다.** 구글 키가 운영에만 있습니다.
